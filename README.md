# 말랑이 AR 🌱

아이폰과 안드로이드에서 모두 동작하는 **웹 AR 프로토타입**입니다.
앱 설치 없이 링크만 열면, 폰 카메라로 비춘 책상 위에 3D 캐릭터 '말랑이'가 올라갑니다.

## 바로 실행하기

| 구분 | 링크 |
|---|---|
| AR 페이지 | https://rilakk2.github.io/malang-ar/ |
| 3D 미리보기 | https://rilakk2.github.io/malang-ar/temp_character.html |

**사용 방법**
1. 폰에서 AR 페이지 링크를 엽니다. (아이폰은 Safari, 안드로이드는 Chrome)
2. 아래 초록색 **📷 책상에 올려보기** 버튼을 누릅니다.
3. 카메라로 책상을 천천히 비추면 말랑이가 실제 크기(키 약 18cm)로 올라갑니다.

PC에서는 AR이 지원되지 않아 3D 화면으로만 볼 수 있습니다.

## 주요 기능

- **크로스 플랫폼 웹 AR**: 하나의 페이지로 iOS와 Android를 모두 지원
- **실제 크기 배치**: 책상 같은 수평면을 인식해 캐릭터를 실제 크기로 고정 배치
- **작은 동작 7가지**: 책상 위에서 벗어나지 않도록 모든 움직임을 작게 설계

| 동작 | 설명 |
|---|---|
| 쉬는 중 | 숨 쉬듯 말랑거리고 가끔 눈을 깜빡임 |
| 아장아장 | 지름 14cm 원을 뒤뚱뒤뚱 한 바퀴 돌고 제자리로 |
| 손 흔들기 | 오른손을 들고 살랑살랑 |
| 두리번 | 몸을 좌우로 돌리며 주변 살피기 |
| 콩 점프 | 2cm 높이의 작은 점프 |
| 풀 흔들기 | 눈을 질끈 감고 머리 위 새싹을 부르르 |
| 꾸벅 졸기 | 눈을 감고 천천히 꾸벅꾸벅 |

자동 모드에서는 쉬다가 동작을 무작위로 하고, 버튼으로 직접 고를 수도 있습니다.

## 사용 기술

| 기술 | 역할 |
|---|---|
| [`<model-viewer>`](https://modelviewer.dev/) | 웹 페이지에서 3D 모델 표시 및 AR 실행 |
| [three.js](https://threejs.org/) | 임시 캐릭터 모델링 및 애니메이션 생성 |
| GitHub Pages | 무료 HTTPS 호스팅 (카메라 사용에 HTTPS 필요) |

**왜 이 방식인가요?**
표준 웹 AR(WebXR)은 안드로이드 Chrome에서는 동작하지만 아이폰 Safari에서는 지원되지 않습니다.
그래서 `<model-viewer>`를 사용해 기기별로 각 OS의 기본 AR 기능을 연결했습니다.

- 안드로이드: WebXR / Scene Viewer
- 아이폰: AR Quick Look

## 캐릭터 모델 교체 방법

현재 캐릭터는 블렌더 모델이 완성되기 전까지 쓰는 **임시 캐릭터**로, 페이지가 열릴 때 three.js로 생성됩니다.

블렌더 모델이 완성되면 `character.glb`라는 이름으로 `index.html`과 같은 위치에 올리면, AR 페이지가 자동으로 그 모델을 사용합니다.

블렌더에서 내보낼 때 체크할 것:
- 형식: glTF 2.0 (`.glb`)
- 크기: 실제 크기 (블렌더 1단위 = 1m)
- 원점: 캐릭터 발바닥 중앙
- 애니메이션 이름: `Idle`, `Walk`, `Wave`, `Look`, `Hop`, `Shake`, `Nap`
  (이름에 `Idle`이 들어간 동작이 기본 대기 동작이 됩니다)

## 알려진 제한

- 아이폰 AR에서는 임시 캐릭터가 움직이지 않고 서 있는 모습으로 표시됩니다.
  (블렌더에서 `.usdz`를 따로 내보내 연결하면 해결 가능)
- 일부 안드로이드 기기는 임시 캐릭터로 AR이 열리지 않을 수 있습니다.
  (`character.glb` 파일을 올리면 해결)
